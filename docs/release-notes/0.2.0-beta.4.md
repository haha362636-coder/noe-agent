把各种 AI 编程助手装进一个聊天软件：一键安装 Claude Code、Codex、Gemini CLI 等，管理多个模型厂商的 API，私聊任意 AI，或者把多个 AI 拖进群里，@ 谁就谁来干活。

### 本次更新

#### 新功能
- **⚔ AI 擂台**：同一个任务同时交给几个 AI，每个 AI 在自己的项目副本里干活、互不干扰。默认盲评（只显示「选手 A / B / C」），并排对比回答、改动的文件、耗时和花费，自动标出最快和最省的选手；你选出胜者后才揭晓身份（还有彩纸 🎉），只有胜者的改动会合并进工作目录，并且可以用时光机一键撤销。战绩会累计成排行榜。群聊里点输入框下的「擂台」按钮或输入 `/arena 任务`；私聊里用 `/arena 任务 @codex` 拉别的 AI 一起比
- **🌍 多语言**：支持简体中文和 English，左下角地球按钮或「设置 → 语言」一键切换。系统消息、命令回复和发给 AI 的提示词也会跟着切换，AI 会用对应语言回复。第一次打开按系统语言自动选择
- **Windows 版**：内置终端改用 Windows 自带的 ConPTY，默认 PowerShell；npm 安装的 CLI（.cmd）可正常调用；支持原生文件夹选择框

#### 修复
- 从欢迎页的群聊模板或「新建群聊」创建群聊后，有时群建好了却没有自动打开
- 启动时界面要等 Codex 的模型目录读取完才显示，有时会空白好几秒
- 群聊里 `@codex` 会把同样用 `codex` 命令驱动的自定义 CLI 一起叫来干活

完整更新记录见 [CHANGELOG](https://github.com/haha362636-coder/noe-agent/blob/main/CHANGELOG.md)。

不确定 Mac 是哪种芯片：点屏幕左上角  →「关于本机」查看「芯片」一栏。

### 安装（Mac）

1. 打开 dmg，把 **Noe Agent** 拖进「应用程序」。
2. 安装包没有经过 Apple 公证，第一次打开如果提示「已损坏」或「无法验证开发者」，在「终端」里执行一次：
   ```bash
   xattr -cr "/Applications/Noe Agent.app"
   ```
3. 正常双击打开。系统要求 macOS 12 及以上。

### 安装（Windows）

1. **先安装** [Node.js](https://nodejs.org)（LTS 版）和 [Git for Windows](https://git-scm.com/download/win)（Claude Code 需要 Git Bash）
2. 双击 `setup.exe` 安装。安装包没有代码签名，如果提示「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**
3. 从桌面或开始菜单打开 Noe Agent

Windows 版比 Mac 版更早期，遇到问题欢迎反馈（附截图和 Windows 版本）。

### 已知问题

- 安装包未经 Apple 公证 / 未做 Windows 代码签名，首次打开需要按上面的步骤操作
- AI 擂台会把工作目录复制到系统临时目录（不含 `node_modules`、`.git`、`dist` 等，上限 2 万个文件 / 300 MB），查看和合并改动需要本机装有 git
- 第三方 CLI 更新频繁，个别命令参数变化后可能需要更新 Noe Agent

### 校验（SHA-256）

Mac 安装包见附件 `SHA256SUMS.txt`（终端执行 `shasum -a 256 文件名` 核对）；Windows 安装包见附件 `SHA256SUMS-windows.txt`（PowerShell 执行 `Get-FileHash 文件名` 核对）。

## English

**Noe Agent** puts all your AI coding assistants into one chat app: one-click install for Claude Code, Codex, Gemini CLI and more, manage APIs from many providers, chat with any AI one-on-one, or drag several AIs into a group and whoever you @ gets to work.

### What's new

- **⚔ AI Arena**: give the same task to several AIs at once, each working in its own copy of your project. Judging is blind by default (just "Contestant A / B / C"): compare answers, changed files, time and cost side by side, with the fastest and cheapest highlighted. Identities are revealed once you pick a winner (with confetti 🎉), and only the winner's changes are merged into your folder, undoable with the Time Machine. Wins add up on a leaderboard. Use the **Arena** button under the input box or `/arena <task>`.
- **🌍 English interface**: switch between English and Simplified Chinese with the globe button at the bottom left or in **Settings → Language**. System messages, command replies and the prompts sent to AIs switch too, so the AIs answer in your language. The first launch follows your system language.
- **Windows build** improvements: ConPTY terminal (PowerShell by default), npm-installed CLIs work, native folder picker.
- **Fixes**: a group created from a template or the New group dialog sometimes didn't open; the UI no longer waits for Codex's model list on startup.
