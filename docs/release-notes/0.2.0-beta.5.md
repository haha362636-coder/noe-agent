- **新应用图标**：石墨渐变底 + 白色 N，和界面配色一致
- 卡片、菜单、对话框、输入框的阴影和描边重新打磨

完整更新记录见 [CHANGELOG](https://github.com/haha362636-coder/noe-agent/blob/main/CHANGELOG.md)。

### 安装（Mac）

1. 打开 dmg，把 **Noe Agent** 拖进「应用程序」（会覆盖旧版本，聊天记录和设置都会保留）。
2. 安装包没有经过 Apple 公证，第一次打开如果提示「已损坏」或「无法验证开发者」，在「终端」里执行一次：
   ```bash
   xattr -cr "/Applications/Noe Agent.app"
   ```
3. 正常双击打开。系统要求 macOS 12 及以上。

> 换了新图标后，程序坞里如果还显示旧图标，把 App 从程序坞移除后重新打开即可。

### 安装（Windows）

1. **先安装** [Node.js](https://nodejs.org)（LTS 版）和 [Git for Windows](https://git-scm.com/download/win)（Claude Code 需要 Git Bash）
2. 双击 `setup.exe` 安装。安装包没有代码签名，如果提示「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**
3. 从桌面或开始菜单打开 Noe Agent

### 已知问题

- 安装包未经 Apple 公证 / 未做 Windows 代码签名，首次打开需要按上面的步骤操作
- 第三方 CLI 更新频繁，个别命令参数变化后可能需要更新 Noe Agent

### 校验（SHA-256）

Mac 安装包见附件 `SHA256SUMS.txt`（终端执行 `shasum -a 256 文件名` 核对）；Windows 安装包见附件 `SHA256SUMS-windows.txt`（PowerShell 执行 `Get-FileHash 文件名` 核对）。

## English

**Noe Agent** puts all your AI coding assistants into one chat app: one-click install for Claude Code, Codex, Gemini CLI and more, manage APIs from many providers, chat with any AI one-on-one, or drag several AIs into a group and whoever you @ gets to work.

### What's new: a fresh look

- **🎨 New grey-and-white theme**: the old indigo/purple is gone. Light mode is ink on white, dark mode is off-white on graphite. Buttons, chat bubbles and the AI Arena are all monochrome; green, orange and red only show up for success, warnings and errors.
- **🏷 Official brand logos**: Claude Code, Codex (its app icon), DeepSeek, Gemini CLI, Qwen Code and OpenCode now use their real logos. Provider lists, the Add provider dialog, the API source menu and the model picker show the matching provider or model logo too. Custom providers and CLIs get a logo when their name matches a known brand. Logos ship inside the app and work offline.
- **🌗 Light / dark switch**: one click at the bottom left, with a little sun / moon animation, or choose "Follow system" in **Settings → Appearance**. Single-color logos turn white in dark mode.
- **New app icon**: white N on a graphite gradient, matching the new theme.
