## Noe Agent 0.2.0-beta.2（Beta 测试版）

> ⚠️ **这是 Beta 测试版，还会有一些问题。** 遇到 Bug 或有建议，欢迎到 [Issues](https://github.com/haha362636-coder/noe-agent/issues) 反馈。

把各种 AI 编程助手装进一个聊天软件：一键安装 Claude Code、Codex、Gemini CLI 等，管理多个模型厂商的 API，私聊任意 AI，或者把多个 AI 拖进群里，@ 谁就谁来干活。

### 本次更新

#### 新功能
- ⌘K 可以搜索所有会话的聊天记录，点击结果直接跳到那条消息
- 同一个 AI 连续收到多条消息时自动排队执行，显示「排队中」
- 正在生成的回复可以单独停止 / 取消排队，不影响其他成员
- 自己发的消息可以「编辑后重新发送」
- 每个会话的输入草稿单独保存，切换会话不丢
- 导出聊天记录为 Markdown（更多菜单）
- 记住窗口大小和位置；重复打开 App 时切回已有窗口

#### 修复
- 安全：本地服务只接受本机页面的请求，防止网页通过本地接口执行命令；外部链接只允许打开 http / mailto
- 访问畸形网址会导致本地服务崩溃
- 群聊里 `@codex write tests` 这类后面跟英文的 @ 无法识别
- 同一个 AI 同时续接同一个会话导致上下文互相覆盖
- 同时打开两个 App 实例会互相覆盖数据
- AI 回复过程中清空 / 删除会话后，消息又重新出现
- 流式输出时回复一直闪烁、几乎看不见
- 设置里工作区填空或接力轮数填非法值时没有校验

#### 性能
- Markdown 渲染结果缓存，新消息到达时不再重新渲染整个列表
- 流式输出限制刷新频率，长回复不再越来越卡
- 长会话只渲染最近 120 条消息，可向上加载更早的
- 数据文件改为紧凑格式，体积约减半

| 你的 Mac | 下载这个 |
|---|---|
| Apple 芯片（M1 / M2 / M3 / M4 …） | `Noe-Agent-0.2.0-beta.2-mac-arm64.dmg` |
| Intel 芯片 | `Noe-Agent-0.2.0-beta.2-mac-x64.dmg` |

不确定是哪种芯片：点屏幕左上角  →「关于本机」查看「芯片」一栏。

### 安装

1. 打开 dmg，把 **Noe Agent** 拖进「应用程序」。
2. 安装包没有经过 Apple 公证，第一次打开如果提示「已损坏」或「无法验证开发者」，在「终端」里执行一次：
   ```bash
   xattr -cr "/Applications/Noe Agent.app"
   ```
3. 正常双击打开。

系统要求：macOS 12 及以上。

### 主要功能

- 一键安装 / 更新 / 卸载 Claude Code、Codex、DeepSeek Harness、Gemini CLI、Qwen Code、OpenCode
- 模型厂商 API 管理（DeepSeek、智谱 GLM、Kimi、阿里云百炼、MiniMax、OpenRouter 等），官方登录与厂商 API 一键切换
- 模型选择器：最新模型目录、搜索、思考强度，`/model opus 5.5`、`/model gpt-6` 模糊匹配
- 私聊与群聊，@ 分派任务，AI 之间互相 @ 接力
- 新会话先选工作目录，回复里的文件链接一点就打开
- `/` 命令与内置终端（官方账号登录、交互式命令）
- MCP 服务器一键安装到多个工具、插件市场与扩展

### 已知问题

- 安装包未经 Apple 公证，首次打开需要执行上面的 `xattr` 命令
- 目前仅支持 macOS
- 第三方 CLI 更新频繁，个别命令参数变化后可能需要更新 Noe Agent

### 校验（SHA-256）

每个安装包的 SHA-256 见附件 `SHA256SUMS.txt`。下载后可以在「终端」里执行 `shasum -a 256 下载的文件.dmg` 核对。
