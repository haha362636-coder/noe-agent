## Noe Agent 0.2.0-beta.3 · Windows 版（首个 Windows 测试版）

> ⚠️ **这是第一个 Windows 版本，比 Mac 版更早期，可能会有问题。** 遇到 Bug 欢迎到 [Issues](https://github.com/haha362636-coder/noe-agent/issues) 反馈，最好附上截图和 Windows 版本。

功能和 Mac 版 0.2.0-beta.3 相同：一键安装 Claude Code、Codex、Gemini CLI 等，管理多个模型厂商的 API，私聊任意 AI，或者把多个 AI 拖进群里，@ 谁就谁来干活。

### 下载

| 文件 | 说明 |
|---|---|
| `Noe-Agent-0.2.0-beta.3-win-x64-setup.exe` | 安装版（推荐），会创建桌面和开始菜单快捷方式 |
| `Noe-Agent-0.2.0-beta.3-win-x64.zip` | 免安装版，解压后双击 `Noe Agent.exe` |

支持 Windows 10（1809 及以上）和 Windows 11，64 位。ARM 版 Windows 也能通过系统自带的 x64 转译运行。

### 安装前准备

Noe Agent 通过 npm 安装各个 AI 工具，所以需要先装：

1. **Node.js**（LTS 版）：<https://nodejs.org>
2. **Git for Windows**：<https://git-scm.com/download/win>（Claude Code 在 Windows 上需要它自带的 Git Bash）

装完后重新打开 Noe Agent。

### 首次打开

安装包没有购买代码签名证书，Windows 可能会弹出「Windows 已保护你的电脑」：点 **更多信息** → **仍要运行** 即可。只有第一次需要。

### 和 Mac 版的区别

- 内置终端默认是 PowerShell（装了 PowerShell 7 会优先用 `pwsh`）
- 快捷键用 `Ctrl`，例如 `Ctrl+K` 快速切换、`Ctrl+J` 打开终端
- 数据保存在 `C:\Users\你的用户名\.noe-agent`
